# Canvasly Project Overview

## Product Name

Canvasly

---

# Vision

Canvasly is a production-grade real-time collaborative whiteboard where teams draw, design, and think together on a shared infinite canvas. Collaboration is a first-class feature from day one, not a plugin grafted onto a single-player drawing tool.

The product combines the fluency of tldraw (a best-in-class open-source canvas engine) with the real-time infrastructure of Liveblocks, the auth ergonomics of Clerk, and the reliability of a serverless Postgres database on Neon. The result is a fast, fluid, multiplayer workspace that rivals Figma FigJam and Miro in experience quality.

Every product decision favors speed of interaction, clarity of collaboration, and polish over feature breadth. A small team should be able to open a shared board and start working in under 10 seconds.

---

# Problem Statement

Existing collaborative whiteboards are either too complex (Figma, Miro) or too shallow (free drawing demos). Teams that want a focused, fast, code-deployable whiteboard lack a clean open architecture reference they can own and extend.

Examples:
- Teams using Figma FigJam pay per seat and cannot self-host or customize the canvas behavior
- Most open-source whiteboard demos have no real auth, no persistent storage, and no multiplayer beyond a toy WebSocket proof of concept
- Miro's collaboration UX is real but its codebase is a proprietary black box
- Building a custom canvas from scratch takes months and produces an inferior result

The problem is that no production-quality, open-architecture collaborative whiteboard exists that a team can deploy on Vercel in minutes and own completely.

---

# Solution

Canvasly solves this by composing the best available tools into a cohesive product.

A core board entity contains:
- A persistent Postgres record (title, org, creator, thumbnail, permissions)
- A Liveblocks room (real-time CRDT storage for tldraw document state)
- A board membership table (roles: owner, editor, commenter, viewer)
- A thumbnail snapshot (auto-generated via Liveblocks webhook, stored via ImageKit)

The solution gives teams a full-featured collaborative whiteboard that is immediately deployable, completely ownable, and extensible without fighting a closed platform.

# Target Audience

Primary Users:
- Product and design teams who want a whiteboard for planning and brainstorming
- Engineering teams using whiteboards for architecture diagrams and system design
- Remote-first teams that need an async canvas for distributed collaboration
- Startups and indie teams who want a self-hosted or Vercel-hosted alternative to Miro

Secondary Users:
- Educators running virtual collaborative classes
- Agencies sharing design explorations with clients
- Individual designers and developers building personal knowledge boards

---

# Core User Journey

User signs in with Clerk
       ↓
User lands on the Dashboard and sees their boards organized by workspace
       ↓
User creates a new board (title auto-generated, board opens immediately)
       ↓
User draws, adds shapes, text, and sticky notes on the infinite canvas
       ↓
User invites a colleague via the Share button. Colleague's cursor appears within 2 seconds
       ↓
Both users work simultaneously. Changes propagate in real-time via Liveblocks CRDT
       ↓
User exports the board as PNG or SVG or shares a read-only public link

---

# Secondary User Journey

User returns to a board they last edited 3 days ago
       ↓
Dashboard shows the thumbnail snapshot (auto-generated by Liveblocks webhook)
       ↓
User opens the board and sees the full canvas state restored from Liveblocks storage
       ↓
User reads anchored comments left by a collaborator
       ↓
User resolves comments and continues editing

# Marketing Landing Page Screen Details

Purpose:
Converts visitors to sign-ups. Communicates value, shows the live canvas, and builds trust through social proof and pricing clarity.

Contains:
- High-impact hero with animated canvas preview, primary CTA ("Start for free"), secondary CTA ("See it live")
- Social proof bar: user count, security badge, "No credit card required" badge
- Interactive bento grid showcasing collaboration, tools, and sharing features
- Live interactive canvas demo (embedded tldraw instance, no auth required)
- Technical deep-dive section: real-time architecture explainer with a system diagram
- User testimonials with authentic names and roles
- Pricing table: Free tier vs Pro tier vs Enterprise with feature comparison matrix
- FAQ accordion with 8 questions
- Full-width footer with nav columns, status indicator, and newsletter CTA

---

# Dashboard Screen Details

Purpose:
Central workspace where users manage all their boards across organizations.

Contains:
- Left sidebar with logo, organization switcher (Clerk), nav links (All Boards, Favorites, Shared with me), and upgrade nudge
- Top bar with search input, New Board button, and user avatar menu
- Board grid: cards with thumbnail, title, last edited timestamp, collaborator avatars, and overflow menu (rename, duplicate, favorite, delete)
- Empty state: icon centered, "Create your first board" CTA using Lucide icons (no emoji, no decorative illustrations)
- Boards are sorted by last updated, filterable by favorites and shared with me

---

# Board Canvas Screen Details

Purpose:
The core product experience. A full-screen, infinite collaborative canvas.

Contains:
- tldraw canvas filling the full viewport
- Floating toolbar (left): draw, select, shapes, text, sticky note, image upload, hand, eraser tools
- Top bar: board title (editable inline), back to dashboard, share button, export button, presence avatars
- Real-time cursors overlaid on the canvas with collaborator names
- Zoom controls (bottom right): fit to screen, zoom in/out, percentage display
- Comments panel (right): open and close, list of anchored comments with resolution state
- Canvas-anchored comment pins: click any canvas area to add a comment

This is the most critical interaction view. Performance here is non-negotiable.

---

# Board Settings Screen Details

Purpose:
Manage a board's title, description, permissions, and danger zone actions.

Contains:
- Title and description edit fields
- Visibility toggle (Private, Organization, Public with link)
- Members list with role dropdowns (per member)
- Invite by email input
- Danger zone: archive board, delete board (with confirmation dialog)
- Board activity feed: last 20 actions with actor, action, and timestamp

The layout should feel like a focused settings panel, not a generic database table.

---

# Share and Invite Dialog Details

Contains:
- Invite by email input with role selector (editor, commenter, viewer)
- Current members list with role chips and remove buttons
- Public link toggle with copy button
- Shareable link with role restriction dropdown
- Expiring link option (1 day, 7 days, 30 days, never)

---

# Empty State Philosophy

Empty states are opportunities. They should feel friendly, motivating, and focused on the next action.

Every empty state uses a Lucide icon (never an emoji), a short motivating headline, a one-line description, and a single primary CTA button. No decorative illustrations. Clarity and action win.

---

# Future Features

Not MVP:
- AI assistant to summarize, label, or auto-arrange canvas content
- Version history timeline with snapshot rewind
- Templates marketplace where boards can be published as reusable starting points
- Voice and video rooms anchored inside a board (LiveKit integration)
- Mobile app using React Native with tldraw mobile adapter
- Zapier and webhook integrations for board events

These features are intentionally excluded from the initial build.

"Can my whole team draw and think together on the same canvas right now?"
without guessing.
