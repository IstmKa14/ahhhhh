# MindBloom Project Overview

## Product Name

MindBloom

---

# Vision

MindBloom is a mental wellness application that assists students with managing anxiety, depression, and stress.

The application features a selection of calming mini games, an empathetic AI chatbot assistant, guided meditations, progress tracking, and personalized recommendations.

The design focuses on simplicity and peace to help users feel relaxed and supported during difficult times.

---

# Problem Statement

Students face high levels of stress and anxiety with few easy resources to help them cope in their daily lives.

Examples:
- Sudden stress during study sessions
- Lack of simple tools to guide daily breathing exercises
- Difficulty tracking mood and sleep trends over time
- Not knowing where to find immediate help or crisis contacts

MindBloom addresses these problems by providing simple and approachable tools in a single place.

---

# Solution

A calm space offering instant stress relief games, an ancient tree AI companion, and direct resources.

A core entity may contain:
- Users (accounts, authentication state, custom profile data)
- Notes (good or bad thoughts saved to the gratitude tree)
- Chat History (messages shared with the ancient tree spirit)
- Journal Entries (text documents recorded by users to trace their feelings)

By combining interactive features and AI support, the app gives users a reliable way to unwind.

---

# Target Audience

Primary Users:
- College and university students facing academic pressure
- Young adults seeking daily wellness practices
- Anyone looking for a calm space to decompress
- People who need quick access to crisis contacts

Secondary Users:
- Healthcare counselors recommending supportive habits
- Educators promoting wellness resources
- Family members supporting a loved one

---

# Core User Journey

User inputs intent / starting action
       ↓
User logs in and visits the dashboard
       ↓
User writes a note about a good or bad thought to grow their tree
       ↓
User interacts with the tree AI chat to receive empathetic reflection
       ↓
User feels a sense of relief and sees their tree grow

---

# Secondary User Journey

User opens app
       ↓
User opens the calming games collection
       ↓
User completes a breathing exercise or plays a relaxing game
       ↓
User views their progress and mood trends in the dashboard
       ↓
User gains insight into their well being and logs out safely

---

# Primary Screens

1. Landing
2. Login and Signup
3. Dashboard
4. Journal and Tree
5. Games
6. Chat
7. Resources
8. Survey

---

# Landing Screen Details

Purpose:
Welcoming users and explaining the core benefits of the app.

Contains:
- Clean hero section with gentle animations
- Core features showcase
- Quick access links to emergency contacts
- Call to action buttons for login and registration

---

# Login and Signup Screen Details

Purpose:
Allowing users to sign in or create a new account securely.

Examples:
- Email and password fields
- Secure password reset flow
- Clean redirect links between login and signup views

The forms should use soft borders and neutral colors.

---

# Dashboard Screen Details

Purpose:
Providing a central hub with mood tracking, progress graphs, and personalized recommendations.

Contains:
- Interactive mood tracking input
- Recharts graphs showing mood and sleep patterns over time
- Personalized suggestions block
- Quick navigation panel to all other tools

This is the most critical interaction view.

---

# Journal and Tree Screen Details

Purpose:
Writing diary entries and growing the gratitude tree.

The tree grows dynamically as the user logs more thoughts.
The layout should feel like a living garden.
Not a generic database table.

---

# Games Screen Details

Contains:
- Breathing Visualizer with smooth circular animations
- Zen Garden for placing soothing natural elements
- Memory Game to focus the mind
- Color Match to ease anxiety
- Direct return buttons to dashboard

---

# Empty State Philosophy

Empty states are opportunities.
They should feel:
- friendly
- motivating
- warm

Every empty state uses clear icons and simple text prompts.

---

# Future Features

Not MVP:
- Peer support community boards
- Wearable device integration
- Audio voice recording analysis for mood
- Advanced custom plant types for the garden
- Professional therapist booking service

These features are intentionally excluded from the initial build.

---

# Success Metric

The app succeeds when users can answer:
"Do I feel calmer and more self aware after using this app?"
without guessing.
